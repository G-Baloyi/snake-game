# 🐍 Snake Game

A classic Snake game implementation using Python and Pygame. Guide your snake to eat food, grow longer, and avoid crashing into walls or yourself!

## 📋 Description

This is a modern take on the classic Snake game. Control a snake that grows longer each time it eats food. The game ends if the snake runs into the screen boundaries or collides with itself. Try to achieve the highest score possible!

## ✨ Features

- **Classic Gameplay**: Traditional snake game mechanics
- **Score Tracking**: Real-time score display showing your progress
- **Smooth Controls**: Responsive arrow key controls
- **Game Over Screen**: Options to restart or quit after losing
- **Visual Feedback**: Clean graphics with contrasting colors

## 🎮 How to Play

1. Run the game
2. Use arrow keys to control the snake's direction
3. Eat the green food blocks to grow your snake and increase your score
4. Avoid hitting the walls or running into yourself
5. Try to achieve the highest score possible!

## 🕹️ Controls

- **Arrow Keys**: Control snake direction
  - ⬆️ **Up Arrow**: Move up
  - ⬇️ **Down Arrow**: Move down
  - ⬅️ **Left Arrow**: Move left
  - ➡️ **Right Arrow**: Move right
- **C**: Play again (after game over)
- **Q**: Quit game (after game over)

## 🛠️ Requirements

- Python 3.x
- Pygame library

## 📦 Installation

1. **Clone the repository**:
   ```bash
   git clone https://github.com/G-Baloyi/snake-game.git
   cd snake-game
   ```

2. **Install Pygame**:
   ```bash
   pip install pygame
   ```

## 🚀 Running the Game

Run the game with:
```bash
python snake.py
```

## 🎯 Game Rules

- The snake starts with a length of 1
- Each food item eaten increases the snake's length by 1
- The score equals the snake's length minus 1
- The game ends if:
  - The snake hits any of the four walls
  - The snake collides with itself

## 🎨 Game Settings

- **Screen Size**: 600x400 pixels
- **Snake Speed**: 15 FPS
- **Snake Block Size**: 10x10 pixels
